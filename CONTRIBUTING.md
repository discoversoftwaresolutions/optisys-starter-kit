# Contributing

Contributions should preserve the purpose of this repository: public, reproducible validation and integration tooling for the OptiSys Headless API.

Requirements:

- use environment variables for credentials and endpoints;
- do not import private OptiSys implementation modules;
- do not embed customer or cloud-account identifiers;
- include reproducible validation instructions;
- do not commit secrets or production logs;
- keep examples marketplace-neutral where practical.
